等角写像による境界値問題

  1. ホーム
  2. 物理数学
  3. 複素関数
  4. 6. いろいろな計算

問題★★★

帯状領域 \(D = \{z = x+iy \mid -\infty < x < \infty, \, 0 < y < \pi\}\) における2次元静電ポテンシャル \(\phi(x, y)\) の境界値問題を等角写像を用いて解く。写像 \(w = e^z\)（\(w = u + iv\)）を用いる。電位は領域内で有界であるとする。(2)の上半平面でも有界な解を求めるものとする。以下の問いに答えよ。

(1)写像 \(w=e^z\) によって，境界の直線 \(y=\pi\) が写る \(w\) 平面上の図形を，\(u,v\) の式で表せ。

(2)\(w\) 平面の上半平面において，実軸上の境界条件が \(u > 0\) で \(\phi = 0\)，\(u < 0\) で \(\phi = V_0\) であるとする。\(V_0\) は正の定数である。ラプラス方程式を満たす電位 \(\phi\) を極座標 \(w = \rho e^{i\theta}\)（\(\rho > 0, 0 < \theta < \pi\)）の偏角 \(\theta = \arg w\) を用いて表せ。

(3)等角写像 \(w = e^z\) を用いて，元の帯状領域における電位分布 \(\phi(x, y)\) を \(x, y\) で表せ。

解答・解説

\(w=e^z\) は，横に長い帯の領域を上半平面に写します。上半平面では，境界条件を満たす電位を偏角の1次式で表すことができます。この電位をもとの帯の座標で書き直すと，電位分布を求めることができます。

(1)

\(z = x + iy\) を代入して \(w = e^z\) の実部と虚部を求めます。

\[ \begin{aligned} w &= e^{x+iy} \\ &= e^x (\cos y + i \sin y) \end{aligned} \]

実部と虚部は

\[ u = e^x \cos y, \quad v = e^x \sin y \]

となります。領域 \(D\) では \(0 < y < \pi\) なので，\(\sin y > 0\) です。また \(e^x > 0\) なので，虚部は \(v > 0\) を満たします。帯 \(D\) は，上半平面全体に1対1に写されます。 境界 \(y = 0\) では，\(u = e^x > 0\)，\(v = 0\) です。この境界は実軸の正の部分に写ります。 境界 \(y = \pi\) では，\(u = -e^x < 0\)，\(v = 0\) です。したがって，求める図形は

\[ \finalanswer{v = 0,\quad u < 0} \]

で表される実軸の負の部分です。

(2)

複素対数関数 \(\mathrm{Log}\, w = \ln \rho + i\theta\) の虚部 \(\theta = \arg w\) は調和関数です。 境界条件を満たす電位を定数 \(A, B\) を用いて

\[ \phi = A\theta + B \]

とおきます。実軸の正の部分は \(\theta = 0\) です。ここで \(\phi = 0\) なので，

\[ B = 0 \]

となります。実軸の負の部分は \(\theta = \pi\) です。ここで \(\phi = V_0\) なので，

\[ A\pi = V_0 \implies A = \frac{V_0}{\pi} \]

です。したがって，求める電位は

\[ \finalanswer{\phi = \frac{V_0}{\pi}\theta} \]

となります。

(3)

写像 \(w = e^z\) と極形式 \(w = \rho e^{i\theta}\) を比べます。

\[ w = e^x e^{iy} = \rho e^{i\theta} \]

両辺の絶対値と偏角を比べると，

\[ \rho = e^x, \quad \theta = y \]

が得られます。この \(\theta = y\) を (2) で求めた電位の式に代入すると，

\[ \finalanswer{\phi(x, y) = \frac{V_0}{\pi} y} \]

となります。電位は \(x\) によらず，\(y\) に比例して変化します。これは，平行平板電極の間の電位分布と同じです。
