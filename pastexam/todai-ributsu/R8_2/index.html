東大理物 令和8年度 第2問

図1左のように片方の端点（始点）が \(x = 0\) に固定され，長さ \(a\) の棒粒子が \(N\) 個連なってできる1次元の高分子を考える。各棒粒子は右向きか左向きか2状態のうちどちらかのみを取る。\(R\) は高分子のもう片方の端点（終点）の \(x\) 座標であり，右向きの棒粒子の数 \(N_+\) と左向きの棒粒子の数 \(N_-\) を用いて \(R = (N_+ - N_-)a\) と表される。この高分子が温度 \(T\) の熱浴に接している状況を考える。以下の設問に答えよ。

(1)\(N_+,\ N_-\) を指定したときに高分子が取りうる配置の数 \(W(N_+, N_-)\) を求め，\(N,\ N_+,\ N_-\) が十分大きいときのエントロピー \(S = k_{\mathrm{B}}\ln W\) を \(r = R/(Na)\) の関数として求めよ。ここで \(k_{\mathrm{B}}\) はボルツマン定数である。必要に応じてスターリングの公式 \(\ln N! \simeq N\ln N - N\) を用いてよい。

(2)終点を \(x = R = Nar\) で固定するために必要な力のうち，エントロピー由来の力

\[ F_{\mathrm{S}} = \frac{T}{Na}\frac{\partial S(r)}{\partial r} \]

を \(r,\ T,\ a\) の関数として求め，\(r\) が小さいときにフックの法則が現れることを示せ。

次に，\(i\) 番目の棒粒子と \(i + 1\) 番目の棒粒子の連結部分のエネルギー \(u_i\) を考慮に入れる。連結部分は曲がっている状態とまっすぐな状態のどちらかを取り，図1右のようにそれぞれのエネルギーは \(u,\ -u\) であるとする。また，高分子の終点には電荷 \(+1\) が付加されており，電場 \(h\) が \(x\) 軸に沿って正の向きにかかっている。\(i\) 番目の棒粒子の向きの変数 \(\sigma_i\) を導入し，右向きのとき \(\sigma_i = 1\)，左向きのとき \(\sigma_i = -1\) とすると，この高分子のエネルギーは

\[ U(\{\sigma\}) = -u\sum_{i=1}^{N-1}\sigma_i\sigma_{i+1} - ha\sum_{i=1}^{N}\sigma_i \]

と表され，1次元のイジング模型と等価になる。以下の設問に答えよ。

(3)棒粒子の向きの変数 \(\sigma_i,\ \sigma_{i+1}\) に依存する関数 \(M_{\sigma_i, \sigma_{i+1}} = \exp[\beta u\sigma_i\sigma_{i+1} + \beta ha(\sigma_i + \sigma_{i+1})/2]\) を使って行列 \(M\) を

\[ M = \begin{pmatrix} M_{1,1} & M_{1,-1} \\ M_{-1,1} & M_{-1,-1} \end{pmatrix} = \begin{pmatrix} e^{\beta u + \beta ha} & e^{-\beta u} \\ e^{-\beta u} & e^{\beta u - \beta ha} \end{pmatrix} \]

とする。このとき，行列 \(M\) の2乗 \(M^2\) の成分 \((M^2)_{1,1},\ (M^2)_{1,-1},\ (M^2)_{-1,1},\ (M^2)_{-1,-1}\) は

\[ (M^2)_{\sigma_1, \sigma_3} = \sum_{\sigma_2 = \pm 1} M_{\sigma_1, \sigma_2} M_{\sigma_2, \sigma_3} = \sum_{\sigma_2 = \pm 1} \exp\left[\beta u\sum_{i=1}^{2}\sigma_i\sigma_{i+1} + \beta ha\sum_{i=1}^{3}\sigma_i - \boxed{\phantom{xxxx}}\right] \]

と書ける。ここで \(\beta = 1/(k_{\mathrm{B}}T)\) である。\(\boxed{\phantom{xx}}\) を埋めよ。

(4)この系の分配関数は

\[ Z = \sum_{\sigma_1 = \pm 1,\, \sigma_N = \pm 1} (M^{N-1})_{\sigma_1, \sigma_N}\exp\bigl[\,\boxed{\phantom{xxxx}}\,\bigr] \]

と書ける。\(\boxed{\phantom{xx}}\) を埋めよ。

(5)棒粒子1つあたりの自由エネルギー

\[ f(h) = \lim_{N \to \infty}\frac{-k_{\mathrm{B}}T\ln Z}{N} \]

を求めよ。ただし，必要に応じて行列 \(M\) の固有値

\[ \lambda_\pm = e^{\beta u}\cosh(\beta ha) \pm \sqrt{e^{2\beta u}\sinh^2(\beta ha) + e^{-2\beta u}} \]

を用いてよい。

(6)\(f(h)\) を \(h = 0\) の付近で \(\beta ha\) の2次まで展開した表式を求めよ。ただし，小さい \(\delta\) に対して \(\cosh(\delta) \simeq 1 + \delta^2/2,\ \sinh(\delta) \simeq \delta\) となることを用いてよい。

(7)\(r\) の関数としての自由エネルギー \(g(r)\) は逆ルジャンドル変換により

\[ g(r) = \min_{h}\bigl[f(h) + rah\bigr] = f(h^*(r)) + rah^*(r) \]

と求まる。ここで，\(h^*(r)\) は \(ra = -\dfrac{\partial f}{\partial h}\) を満たす \(h\) である。問6の結果を用いて，\(h^*(r)\) を \(r\) の最低次の関数として求めよ。

(8)電場がないとき（\(h = 0\)）に終点を \(x = R = Nar\) で固定するために必要な力

\[ F = -\frac{1}{a}\frac{\partial g(r)}{\partial r} \]

を，\(r\) が小さいときについて \(r,\ T,\ a,\ u\) の関数として求めよ。また，\(F\) と問2で求めた \(F_{\mathrm{S}}\) をそれぞれ \(R,\ T,\ N,\ a,\ u\) の関数として表したとき，\(F_{\mathrm{S}}\) の表式において棒粒子の長さ \(a\) を実効的な棒粒子の長さ \(\tilde{a}\) に置き換えることで \(F\) が得られることを示し，\(u\) が正の場合，負の場合それぞれについて，\(\tilde{a}\) と \(a\) の大小関係を答えよ。また，なぜそのようになるか，物理的な解釈を述べよ。

出典：東京大学大学院理学系研究科物理学専攻 令和8年度修士課程入学試験 専門科目 第2問（引用元：https://www.phys.s.u-tokyo.ac.jp/）。Web掲載にあたり数式をテキスト化し，図を描き直しています。解答・解説は当サイトが独自に作成したもので，東京大学が公表したものではありません。

解答・解説

相互作用がない鎖では，棒のエネルギーは向きによらないので，鎖を引き戻す力はエントロピーから生じます。終点の位置を決めると右向きと左向きの棒の本数が決まるので，並べ方の数からエントロピーを求め，終点の位置で微分して力を計算します。

隣り合う棒に相互作用があると，棒の向きを1本ずつ独立に数えることができません。そこで，隣り合う2本の向きの組ごとのボルツマン因子を2行2列の行列 \(M\) に並べます。分配関数は \(M\) の積で書くことができ，\(N\) が大きいときは \(M\) の大きいほうの固有値の \(N\) 乗が主な項になります。

終点を固定した鎖を直接数えるのは難しいので，終点に力 \(h\) を加えた鎖の自由エネルギー \(f(h)\) をまず求めます。終点を固定した鎖の自由エネルギーは，\(f(h)\) をルジャンドル変換して求めます。

(1)

右向きの棒粒子が \(N_+\) 個，左向きの棒粒子が \(N_-\) 個あるので，全部で \(N = N_+ + N_-\) 個の棒粒子のうちどれが右向きになるかを選ぶ組み合わせが配置の数です。したがって，

\[ \finalanswer{W(N_+, N_-) = \frac{N!}{N_+!\,N_-!} = \frac{(N_+ + N_-)!}{N_+!\,N_-!}} \]

次に，\(N_+ + N_- = N\) と \(R = (N_+ - N_-)a = Nar\) を連立して \(N_+\) と \(N_-\) を \(N\) と \(r\) で表します。

\[ N_+ = \frac{N(1 + r)}{2},\qquad N_- = \frac{N(1 - r)}{2} \]

\(N,\ N_+,\ N_-\) が十分大きいとして，スターリングの公式 \(\ln N! \simeq N\ln N - N\) をエントロピー \(S = k_{\mathrm{B}}\ln W\) に用います。

\[ \begin{aligned} S &= k_{\mathrm{B}}\bigl(\ln N! - \ln N_+! - \ln N_-!\bigr) \\ &\simeq k_{\mathrm{B}}\bigl(N\ln N - N - N_+\ln N_+ + N_+ - N_-\ln N_- + N_-\bigr) \\ &= k_{\mathrm{B}}\bigl(N\ln N - N_+\ln N_+ - N_-\ln N_-\bigr) \\ &= -k_{\mathrm{B}}\left(N_+\ln\frac{N_+}{N} + N_-\ln\frac{N_-}{N}\right) \end{aligned} \]

ここで \(N_+ + N_- = N\) を用いて定数項と \(\ln N\) の項をまとめました。\(N_+/N = (1+r)/2\) と \(N_-/N = (1-r)/2\) を代入すると，求めるエントロピーが得られます。したがって，

\[ \finalanswer{S(r) = -N k_{\mathrm{B}}\left(\frac{1 + r}{2}\ln\frac{1 + r}{2} + \frac{1 - r}{2}\ln\frac{1 - r}{2}\right)} \]

(2)

問1で求めた \(S(r)\) を \(r\) で偏微分します。

\[ \begin{aligned} \frac{\partial S(r)}{\partial r} &= -N k_{\mathrm{B}}\left[\frac{1}{2}\left(\ln\frac{1 + r}{2} + 1\right) - \frac{1}{2}\left(\ln\frac{1 - r}{2} + 1\right)\right] \\ &= -\frac{N k_{\mathrm{B}}}{2}\ln\frac{1 + r}{1 - r} \end{aligned} \]

これを \(F_{\mathrm{S}} = \dfrac{T}{Na}\dfrac{\partial S(r)}{\partial r}\) に代入します。したがって，

\[ \finalanswer{F_{\mathrm{S}} = -\frac{k_{\mathrm{B}}T}{2a}\ln\frac{1 + r}{1 - r}} \]

\(|r| \ll 1\) のとき，\(\ln(1 \pm r) \simeq \pm r\) と1次まで展開すると，\(\ln\dfrac{1+r}{1-r} \simeq 2r\) となります。これを用いると，\(F_{\mathrm{S}}\) は次のようになります。

\[ \begin{aligned} F_{\mathrm{S}} &\simeq -\frac{k_{\mathrm{B}}T}{a}r \\ &= -\frac{k_{\mathrm{B}}T}{Na^2}R \end{aligned} \]

このように，\(r\) が小さいときには力 \(F_{\mathrm{S}}\) が終点の変位 \(R\) に比例するフックの法則が現れます。ばね定数にあたる係数 \(\dfrac{k_{\mathrm{B}}T}{Na^2}\) は温度 \(T\) に比例します。

(3)

\(M_{\sigma_1, \sigma_2}\) と \(M_{\sigma_2, \sigma_3}\) の定義を代入して積をまとめます。

\[ \begin{aligned} M_{\sigma_1, \sigma_2} M_{\sigma_2, \sigma_3} &= \exp\left[\beta u\sigma_1\sigma_2 + \frac{\beta ha}{2}(\sigma_1 + \sigma_2)\right] \exp\left[\beta u\sigma_2\sigma_3 + \frac{\beta ha}{2}(\sigma_2 + \sigma_3)\right] \\ &= \exp\left[\beta u(\sigma_1\sigma_2 + \sigma_2\sigma_3) + \beta ha\left(\frac{\sigma_1}{2} + \sigma_2 + \frac{\sigma_3}{2}\right)\right] \\ &= \exp\left[\beta u\sum_{i=1}^{2}\sigma_i\sigma_{i+1} + \beta ha\sum_{i=1}^{3}\sigma_i - \frac{\beta ha}{2}(\sigma_1 + \sigma_3)\right] \end{aligned} \]

両端の \(\sigma_1\) と \(\sigma_3\) だけは係数が \(\dfrac{1}{2}\) しか入らないため，和 \(\displaystyle\sum_{i=1}^{3}\sigma_i\) から両端の半分を引く形になります。したがって，空欄に入る式は次のようになります。

\[ \finalanswer{\frac{\beta ha}{2}(\sigma_1 + \sigma_3)} \]

(4)

問3と同じ計算を \(N - 1\) 個の行列 \(M\) の積に広げると，途中の \(\sigma_2, \dots, \sigma_{N-1}\) は係数が1にそろい，両端の \(\sigma_1\) と \(\sigma_N\) だけが半分だけ不足します。

\[ (M^{N-1})_{\sigma_1, \sigma_N} = \sum_{\sigma_2 = \pm 1}\cdots\sum_{\sigma_{N-1} = \pm 1} \exp\left[\beta u\sum_{i=1}^{N-1}\sigma_i\sigma_{i+1} + \beta ha\sum_{i=1}^{N}\sigma_i - \frac{\beta ha}{2}(\sigma_1 + \sigma_N)\right] \]

分配関数は \(Z = \displaystyle\sum_{\{\sigma\}}\exp[-\beta U(\{\sigma\})]\) なので，不足している両端の因子 \(\exp\left[\dfrac{\beta ha}{2}(\sigma_1 + \sigma_N)\right]\) を掛けてから \(\sigma_1, \sigma_N\) について和をとれば \(Z\) に一致します。したがって，空欄に入る式は次のようになります。

\[ \finalanswer{\frac{\beta ha}{2}(\sigma_1 + \sigma_N)} \]

(5)

ベクトル \(\boldsymbol{w} = \begin{pmatrix} e^{\beta ha/2} \\ e^{-\beta ha/2} \end{pmatrix}\) を導入すると，問4の分配関数は \(Z = \boldsymbol{w}^\top M^{N-1}\boldsymbol{w}\) と書くことができます。

行列 \(M\) は実対称行列なので，固有値 \(\lambda_+,\ \lambda_-\) に属する正規直交固有ベクトル \(\boldsymbol{v}_+,\ \boldsymbol{v}_-\) をとることができます。これを用いて \(M^{N-1}\) を展開すると，次のようになります。

\[ Z = c_+\lambda_+^{N-1} + c_-\lambda_-^{N-1},\qquad c_\pm = \bigl(\boldsymbol{v}_\pm^\top \boldsymbol{w}\bigr)^2 \]

固有値の表式から \(e^{\beta u}\cosh(\beta ha) > 0\) かつ \(\sqrt{e^{2\beta u}\sinh^2(\beta ha) + e^{-2\beta u}} > 0\) なので，\(\lambda_+ > |\lambda_-|\) が成り立ちます。また，\(M\) の成分はすべて正なので，\(\lambda_+\) に属する固有ベクトル \(\boldsymbol{v}_+\) の2成分は同符号となり，正の成分をもつ \(\boldsymbol{w}\) との内積から \(c_+ > 0\) です。

\(Z\) を \(c_+\lambda_+^{N-1}\) でくくって対数をとります。

\[ \frac{\ln Z}{N} = \frac{N - 1}{N}\ln\lambda_+ + \frac{1}{N}\ln c_+ + \frac{1}{N}\ln\left[1 + \frac{c_-}{c_+}\left(\frac{\lambda_-}{\lambda_+}\right)^{N-1}\right] \]

\(|\lambda_-/\lambda_+| < 1\) より \(N \to \infty\) で右辺の第2項と第3項は \(0\) に収束し，\(\dfrac{\ln Z}{N} \to \ln\lambda_+\) となります。したがって，棒粒子1つあたりの自由エネルギーは次のようになります。

\[ \finalanswer{f(h) = -k_{\mathrm{B}}T\ln\left(e^{\beta u}\cosh(\beta ha) + \sqrt{e^{2\beta u}\sinh^2(\beta ha) + e^{-2\beta u}}\right)} \]

(6)

\(\delta = \beta ha\) とおき，\(|\delta| \ll 1\) のもとで \(\lambda_+\) を \(\delta\) の2次まで展開します。まず，平方根の部分を近似式 \(\sinh\delta \simeq \delta\) と \(\sqrt{1 + \varepsilon} \simeq 1 + \varepsilon/2\) で展開します。

\[ \begin{aligned} \sqrt{e^{2\beta u}\sinh^2\delta + e^{-2\beta u}} &\simeq e^{-\beta u}\sqrt{1 + e^{4\beta u}\delta^2} \\ &\simeq e^{-\beta u}\left(1 + \frac{1}{2}e^{4\beta u}\delta^2\right) \\ &= e^{-\beta u} + \frac{1}{2}e^{3\beta u}\delta^2 \end{aligned} \]

これに \(e^{\beta u}\cosh\delta \simeq e^{\beta u}\left(1 + \dfrac{\delta^2}{2}\right)\) を足して \(\lambda_+\) を整理します。

\[ \begin{aligned} \lambda_+ &\simeq \left(e^{\beta u} + e^{-\beta u}\right) + \frac{1}{2}\left(e^{\beta u} + e^{3\beta u}\right)\delta^2 \\ &= \left(e^{\beta u} + e^{-\beta u}\right) + \frac{1}{2}e^{2\beta u}\left(e^{-\beta u} + e^{\beta u}\right)\delta^2 \\ &= 2\cosh(\beta u)\left(1 + \frac{1}{2}e^{2\beta u}\delta^2\right) \end{aligned} \]

対数公式 \(\ln(1 + \varepsilon) \simeq \varepsilon\) を用いて \(f(h) = -k_{\mathrm{B}}T\ln\lambda_+\) を \(\delta = \beta ha\) の2次まで求めます。したがって，

\[ \finalanswer{f(h) \simeq -k_{\mathrm{B}}T\ln\bigl(2\cosh(\beta u)\bigr) - \frac{k_{\mathrm{B}}T}{2}e^{2\beta u}(\beta ha)^2} \]

なお，\(\beta = 1/(k_{\mathrm{B}}T)\) を用いると第2項は \(-\dfrac{a^2 e^{2\beta u}}{2k_{\mathrm{B}}T}h^2\) と書くこともできます。

(7)

問6で求めた \(f(h)\) を \(h\) で微分し，条件 \(ra = -\dfrac{\partial f}{\partial h}\) に代入します。

\[ \begin{aligned} -\frac{\partial f}{\partial h} &\simeq \frac{a^2 e^{2\beta u}}{k_{\mathrm{B}}T}h \\ &= ra \end{aligned} \]

これを \(h\) について解きます。したがって，最低次の \(h^*(r)\) は次のようになります。

\[ \finalanswer{h^*(r) \simeq \frac{k_{\mathrm{B}}T}{a}e^{-2\beta u}r = \frac{k_{\mathrm{B}}T}{a}e^{-2u/(k_{\mathrm{B}}T)}r} \]

(8)

問7の \(h^*(r)\) を \(g(r) = f(h^*(r)) + rah^*(r)\) に代入し，\(r\) の2次まで求めます。

\[ \begin{aligned} g(r) &\simeq -k_{\mathrm{B}}T\ln\bigl(2\cosh(\beta u)\bigr) - \frac{a^2 e^{2\beta u}}{2k_{\mathrm{B}}T}\left(\frac{k_{\mathrm{B}}T}{a}e^{-2\beta u}r\right)^2 + ra\left(\frac{k_{\mathrm{B}}T}{a}e^{-2\beta u}r\right) \\ &= -k_{\mathrm{B}}T\ln\bigl(2\cosh(\beta u)\bigr) + \frac{k_{\mathrm{B}}T}{2}e^{-2\beta u}r^2 \end{aligned} \]

これを \(F = -\dfrac{1}{a}\dfrac{\partial g(r)}{\partial r}\) に代入します。したがって，

\[ \finalanswer{F \simeq -\frac{k_{\mathrm{B}}T}{a}e^{-2u/(k_{\mathrm{B}}T)}r} \]

次に，\(r = \dfrac{R}{Na}\) を代入して，\(F_{\mathrm{S}}\) と \(F\) をそれぞれ \(R,\ T,\ N,\ a,\ u\) の関数として表します。

\[ \begin{aligned} F_{\mathrm{S}} &\simeq -\frac{k_{\mathrm{B}}T R}{Na^2} \\ F &\simeq -\frac{k_{\mathrm{B}}T R}{Na^2}e^{-2u/(k_{\mathrm{B}}T)} \\ &= -\frac{k_{\mathrm{B}}T R}{N\bigl(a e^{u/(k_{\mathrm{B}}T)}\bigr)^2} \end{aligned} \]

これより，\(F_{\mathrm{S}}\) の表式で棒粒子の長さ \(a\) を

\[ \finalanswer{\tilde{a} = a e^{u/(k_{\mathrm{B}}T)}} \]

に置き換えると \(F\) が得られます。指数関数の性質から，大小関係は次のようになります。

  • \(u > 0\) のとき：\(\tilde{a} > a\)
  • \(u < 0\) のとき：\(\tilde{a} < a\)

物理的な解釈は次のとおりです。

\(u > 0\) のときは，連結部分がまっすぐな状態のエネルギー \(-u\) のほうが曲がった状態のエネルギー \(u\) よりも低くなります。そのため，隣り合う棒粒子が同じ向きにそろいやすくなり，複数の棒粒子がまとまって1本の長い棒のように振る舞います。結果として実効的な棒の長さ \(\tilde{a}\) が \(a\) より大きくなり，同じ伸び \(R\) に対する復元力 \(|F|\) は小さくなります。

逆に \(u < 0\) のときは，連結部分が折れ曲がった状態のエネルギー \(u\) のほうがまっすぐな状態のエネルギー \(-u\) よりも低くなります。隣り合う棒粒子が互いに逆向きに折り返しやすくなり，変位が打ち消し合うため，実効的な棒の長さ \(\tilde{a}\) は \(a\) より小さくなります。

補足

原本の問7は \(\min_h[f(h)+rah]\) と書いていますが，\(f''(h)<0\) なので，指定された停留点は最大値を与えます。実際，\(|r|<1\) では \(h\to\pm\infty\) の片方で \(f(h)+rah\to-\infty\) となり，有限の最小値はありません。問題文は原本のままとし，解答では併記された停留条件を使っています。自由エネルギーを与える変換としては \(\sup_h[f(h)+rah]\) です。

有限の開いた鎖での距離の分散は，\(t_u=\tanh(\beta u)\) とすると，

\[ \langle R^2\rangle=a^2\left[N+2\sum_{j=1}^{N-1}(N-j)t_u^j\right] \]

です。\(N\to\infty\) で \(\langle R^2\rangle/N\to a^2(1+t_u)/(1-t_u)=a^2e^{2\beta u}\) となります。\(N\tilde a^2\) との一致はこの極限の主項であり，有限Nの厳密な等式ではありません。
