# 東大理物 過去問（令和8年度〜平成8年度）と本編・関連過去問の結びつき一覧

東京大学大学院理学系研究科物理学専攻（東大理物）の公開済み過去問 **174問** について，本編問題（`docs/01mechanics`〜`docs/14calculus` の全771問）との対応および別年度の類題（関連過去問）を整理したマッピング資料です。サイト上の相互リンク実装の元データとしてそのまま利用できる形式で記述しています。

## 実装メモ（Claude向け）

- **現行の関連リンクの仕組み**：`hooks/related_problems.txt` と `hooks/problem_layout.py` の `_related_html` が本編14分野の問題ページ下部に「関連」ブロック（最大5件）を自動挿入しています。現行の正規表現は `(\d\d[a-z_]+)/\d\d/(\d\d_\d\d\d)\.md$` のみを対象としているため，過去問ページ（`docs/pastexam/todai-ributsu/*.md`）には未対応です。
- **キー表記の規約（すべて `docs/` 実在検証済み）**
  - 本編問題キー：`<分野フォルダ>/<問題ステム>`（例：`01mechanics/11_910` → 実ファイル `docs/01mechanics/11/11_910.md`，`hooks/related_problems.txt` と同一形式）
  - 過去問キー：`<問題ステム>`（例：`R8_1` → 実ファイル `docs/pastexam/todai-ributsu/R8_1.md`）
- **推奨される導線の実装方針**
  1. **過去問ページ側**：解説の下に「関連する本編の問題（本ファイルの優先順で最大5件）」と「関連する過去問（別年度の類題，最大3〜5件）」を表示する。
  2. **本編ページ側（逆引き）**：本ファイルの本編キー→過去問キーを逆引きし，既存の「関連」ブロックの下または別セクションに「このテーマの過去問（新年度順で最大3〜5件）」を表示する。
  3. **機械パース**：各問題は ``#### `<stem>` `` で始まり，直下に `- **関連する本編の問題**` / `- **関連する過去問**` の箇条書きが並ぶ統一構造です。各項目先頭のバッククォート内のキーをそのまま抽出して `hooks/related_pastexam.txt` や JSON へ変換できます。
- **対称性**：過去問どうしの関連リンクはすべて双方向に対称（A→B があれば B→A も記載）になっています。
