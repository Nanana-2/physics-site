# 院試の過去問

院試の過去問の PDF と，その使い方の取り決めです。このフォルダはサイトには公開されません（`docs/` の外にあるため）。

## 置き場所

- 東京大学大学院理学系研究科物理学専攻（東大理物）：このリポジトリの `pastexam/todai-ributsu/`。二次利用が認められているので，公開リポジトリに置いています。
- ほかの大学：公開リポジトリには置かず，非公開リポジトリ `Nanana-2/physics-site-private` の `pastexam/<大学>/` に置きます。サイトへの掲載は保留しています。

## サイトに載せるときの決まり（東大理物）

物理学専攻が示している二次利用の条件に従います。

1. 東京大学大学院理学系研究科物理学専攻の大学院入試問題からの引用であることを書き，引用元として専攻の Web ページ https://www.phys.s.u-tokyo.ac.jp/ を明示する。
2. 問題文を原本どおりに載せないとき（書き直し，抜粋，図の描き直しなど）は，改変したことを明示する。
3. 解答・解説は大学が公表したものではないことを明示する。
4. 大学以外の第三者に著作権があるもの（論文の図など）は，そのまま使わない。
5. 商用利用はしない。過去問のページには，Amazon の紹介リンクなど収益につながるものを置かない。

## 解く問題

力学・電磁気学・熱力学・量子力学・統計力学・物性・数学の問題だけを解く。相対論，素粒子論，実験の問題は解かない（ドラフトを作らない）。

東大理物は，次の大問だけを解く。

- 令和2年度以前の物理学：第1〜3問（全員が解く必須問題）だけ。第4〜6問（選択問題）は解かない。
- 令和2年度以前の数学：全問。
- 令和4年度以降の専門科目：第1〜4問の全問。

平成8〜12年度の一般教育科目をどう扱うかは，まだ決めていない。

## ドラフト作成の規則

解答・解説の書き方は，悪い例とよい例を並べて `.agents/rules/pastexam-writing.md` にまとめてある。Antigravity はこのファイルを自動で読む。

### 置き場所とファイル名
- Markdown 原稿は `pastexam/<大学>/drafts/<年度>_<大問番号>.md`（例：`pastexam/todai-ributsu/drafts/R8_1.md`）に置く。令和2年度以前は科目を入れて `R2_butsuri_1.md`，`R2_sugaku_1.md` とする。平成8〜12年度の一般教育科目は `H12_ippan_sugaku_1.md`，`H12_ippan_butsuri_1.md` とし，題名は `東大理物 平成12年度 一般教育科目 物理学 第1問：〜` とする。`docs/` の外に置き，サイトへの組み込みはデザイン担当が行う。
- TikZ 原稿は `figures/src/pastexam-<大学>/<年度>_<大問番号>-p.tex`（複数あるときは `-p1.tex`，`-p2.tex`）に置く。`python3 tools/figures/build.py` でライト用・ダーク用の SVG を `docs/assets/figures/pastexam-<大学>/` に生成し，PNG 化して文字の重なりがないか目視確認する。

### フロントマターと見出し
- YAML フロントマターに `title`，`tags`（`院試過去問`・大学名・分野タグ。分野タグは本編の14分野の名前から選ぶ），`exam_university`，`exam_year`，`exam_subject`，`exam_number`，`exam_source_url`，`exam_modified` を必ず入れる。
- `title` と `#` 見出しは `東大理物 令和8年度 第1問：<短い題名>` の形にそろえる（問題ボックスの帯見出しに `過去問` ではなく `東大理物・令和8年度 第1問` をそのまま出せるようにするため）。
- 出典・引用元 URL・改変の明示と，解答・解説が大学の公表したものでないことの注記は，`## 問題` の末尾に1つの引用ブロック（`> 出典：〜`）にまとめて置く。`## 解答・解説` の直下には注記を置かない。

### 問題文の扱い（原本優先）
- 原本の言い回し，式番号 `(1)`，`(2)`，小問参照（「問3」「図1左」など），空欄枠（`\boxed{...}`）は勝手に書き換えない。`CLAUDE.md` の「問題の作り方」の制約（式番号を `(A)` にする，小問2〜3個，「議論せよ」禁止など）は過去問の引用本文には適用しない。
- 図の参照は `pastexam/<大学>/drafts/` からの正しい相対パス（`../../../docs/assets/figures/pastexam-<大学>/...`）にし，原本の図キャプションを `<figcaption markdown="span">` で残す（`markdown="span"` がないとキャプションの数式が表示されない）。図は `<figure class="problem-figure" markdown>` の中に `![…](…-light.svg#only-light)` と `![…](…-dark.svg#only-dark)` を並べる形にする（`<img class="only-light">` ではライト用とダーク用が両方出てしまう）。

### 問題文の組み方
- `## 問題` と `## 解答・解説` の間に `---` の行を置く。これがないと問題の箱ができない。
- 小問は，原本が「1.」「問1」などでも，行頭に `(1)` を書いた段落にする（`1.` の番号付き箇条書きにしない）。
- 小問の中の小問 (a)，(b) や (i)，(ii) は，箇条書き（`- (a)`）にせず，行頭に `(a)` を書いた段落にする。問題の箱の中で，小問 (1) より1段下げて表示される。
- 小問の途中で設定を足す前置きの段落（「以下，〜の場合を考える。」など）は，小問の続きとして下げずに表示される。段落が「以下，」「以下では」「以下の設問では」「以下の小問では」「次に，」「つぎに，」「最後に，」「続いて，」で始まるときは自動でそうなる。それ以外の書き出しのときは，段落の次の行に `{: .problem-lead }` を書く。
- 出典の注記（`> 出典：〜`）は，問題文の最後に細い線で区切って表示される。
- 問題の帯には，題名の「：」より前（`東大理物 令和8年度 第1問`）が出る。

### 「考え方」と「補足」
- 「考え方」は `CLAUDE.md` の規則に従い，「この問題では〜を確かめます」のような手順の要約やあらすじ紹介にしない。
- 既存総合問題（`docs/01mechanics/11/11_910.md`，`docs/04quantum_mechanics/17/17_910.md`）と同じく，「なぜこの道具・対称性・近似で問題が解けるのか」という物理・数学的な見通しだけを1〜2段落（各段落2〜3行・120字程度）で書く。
- 模型の名称紹介や定在波・極限・特殊ケースの詳しい解釈は末尾の `<aside class="rigor-note" markdown>`（補足）へ移す。

### 解答・解説の数式と文体
- 変形の途中式を省かず，2段以上の式変形は `\begin{aligned}...\end{aligned}` で等号揃えにして1行1段で見せる。
- 変形の途中を飛ばさない。答えだけを書いたり，文中の数式で計算をつないだりせず，途中式を `aligned` で1行1段に並べる。
- 文中の（ ）で補足を差し込まない。残してよいのは数式の条件（$x>0$ など），（図1）のような参照，小問番号だけ。
- 「見通しよく決まります」「典型例です」「鮮やかに」「本質的に」のような，評価や感想を述べる言い方をしない。解答に関係しない話題（ほかの年度の問題への言及，応用例や雑学）は，補足にも書かない。
- `\finalanswer{...}` は値を求める小問の最終結果だけに使い，「〜を示せ」の証明小問の結論には付けない。
- 解説本文は `CLAUDE.md` の文体規則（全角句読点「，」「。」，丁寧語，短縮可能形「計算できます」「表せます」の禁止，禁止語句，数式内日本語の禁止，文中分数は `\dfrac`，微分の `\mathrm{d}`）を厳守し，コミット前に自動点検と数値検算を行う。
