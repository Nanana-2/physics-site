# 院試の過去問

院試の過去問の PDF と，その使い方の取り決めです。このフォルダはサイトには公開されません（`docs/` の外にあるため）。

## 置き場所

- 東京大学大学院理学系研究科物理学専攻（東大理物）：このリポジトリの `pastexam/todai-ributsu/`。二次利用が認められているので，公開リポジトリに置いています。
- ほかの大学：公開リポジトリには置かず，非公開リポジトリ `Nanana-2/physics-site-private` の `pastexam/<大学>/` に置きます。サイトへの掲載は保留しています。

## 東大理物のファイル

ファイル名は `<入試の年度>_<科目>.pdf` です。年度は表紙の「〜年度」で，試験の実施はその前年の8月です。

| ファイル | 内容 |
|---|---|
| `H29_butsuri.pdf`，`H29_sugaku.pdf` | 平成29年度 物理学，数学 |
| `H30_butsuri.pdf`，`H30_sugaku.pdf` | 平成30年度 物理学，数学 |
| `H31_butsuri.pdf`，`H31_sugaku.pdf` | 平成31年度 物理学，数学 |
| `R2_butsuri.pdf`，`R2_sugaku.pdf` | 令和2年度 物理学，数学 |
| `R4_senmon.pdf` 〜 `R8_senmon.pdf` | 令和4〜8年度 専門科目 |

令和3年度は，新型コロナウイルス感染症の影響で筆記試験が行われなかったため，ありません。令和4年度から，物理学と数学は専門科目にまとまっています。多くは画像の PDF で，文字は取り出すことができません。

## サイトに載せるときの決まり（東大理物）

物理学専攻が示している二次利用の条件に従います。

1. 東京大学大学院理学系研究科物理学専攻の大学院入試問題からの引用であることを書き，引用元として専攻の Web ページ https://www.phys.s.u-tokyo.ac.jp/ を明示する。
2. 問題文を原本どおりに載せないとき（書き直し，抜粋，図の描き直しなど）は，改変したことを明示する。
3. 解答・解説は大学が公表したものではないことを明示する。
4. 大学以外の第三者に著作権があるもの（論文の図など）は，そのまま使わない。
5. 商用利用はしない。過去問のページには，Amazon の紹介リンクなど収益につながるものを置かない。
