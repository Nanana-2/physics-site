強制振動と共鳴

  1. ホーム
  2. 力学
  3. 5. 単振動・減衰振動・強制振動

問題★★★

水平面上で，ばね定数 \(k\) の軽いばねに取り付けられた質量 \(m\) の質点を考える。ばねが自然長となる位置を \(x=0\) とする。

質点には復元力と速度に比例する抵抗力 \(-\gamma\dot{x}\) に加え，周期外力 \(F(t)=F_0\cos\omega t\) が働く。ただし \(\gamma>0\)，\(F_0>0\)，\(\omega>0\) とする。

十分な時間が経過すると，初期条件に依存する成分は減衰し，質点は外力と同じ角振動数で振動する。この運動を強制振動の定常状態と呼ぶ。

(1)質点の運動方程式を書き下し，固有角振動数 \(\omega_0 = \sqrt{\dfrac{k}{m}}\) および減衰係数 \(\beta = \dfrac{\gamma}{2m}\) を用いて，次の形式に整理せよ。

\[ \ddot{x} + 2\beta \dot{x} + \omega_0^2 x = f_0 \cos \omega t \]

ここで，\(\dot{x} = \dfrac{dx}{dt}\)，\(\ddot{x} = \dfrac{d^2x}{dt^2}\)，および \(f_0 = \dfrac{F_0}{m}\) である。

(2)十分に時間が経過した後の定常解を，振幅 \(A>0\) と外力に対する位相の遅れ \(0\leq\phi\leq\pi\) を用いて，次のようにおく。

\[ x(t) = A \cos(\omega t - \phi) \]

この解を (1) の運動方程式に代入することにより，振幅 \(A\) および \(\tan \phi\) を \(\omega_0\)，\(\beta\)，\(f_0\)，\(\omega\) を用いて表せ。

(3)振幅 \(A(\omega)\) が極大値をとる共鳴角振動数 \(\omega_r\) を求めよ。また，\(\omega_r>0\) が存在するために減衰係数 \(\beta\) が満たすべき条件を，\(\omega_0\) を用いて示せ。

(4)外力の角振動数 \(\omega\) に対する位相の遅れ \(\phi(\omega)\) を調べる。次の3つの場合について，\(\phi\) の値を求めよ。(i) \(\omega \to 0\) (ii) \(\omega = \omega_0\) (iii) \(\omega \to \infty\)

解答・解説

十分に時間がたつと，初期条件による部分は減衰して消えます。そして，外力と同じ角振動数の振動だけが残ります。この定常解を三角関数でおいて運動方程式に代入し，振幅と位相の遅れを求めます。

(1)

質点には，ばねからの復元力 \(-kx\)，速度に比例する抵抗力 \(-\gamma \dot{x}\)，外力 \(F_0 \cos \omega t\) がはたらきます。したがって，運動方程式は次のようになります。

\[ m \ddot{x} = -kx - \gamma \dot{x} + F_0 \cos \omega t \]

この式の両辺を \(m\) で割って整理します。

\[ \ddot{x} + \frac{\gamma}{m} \dot{x} + \frac{k}{m} x = \frac{F_0}{m} \cos \omega t \]

与えられた定義 \(\omega_0 = \sqrt{\dfrac{k}{m}}\)，\(\beta = \dfrac{\gamma}{2m}\)，\(f_0 = \dfrac{F_0}{m}\) を代入すると，次の運動方程式が得られます。

\[ \finalanswer{\ddot{x} + 2\beta \dot{x} + \omega_0^2 x = f_0 \cos \omega t} \]

(2)

定常解は複素数を用いて求めます。運動方程式の右辺を \(f_0 e^{i\omega t}\) に置き換えた，次の方程式を考えます。

\[ \ddot{z} + 2\beta \dot{z} + \omega_0^2 z = f_0 e^{i\omega t} \]

この方程式の解 \(z(t)\) の実部 \(\operatorname{Re}[z(t)]\) は，もとの方程式の解 \(x(t)\) になります。複素振幅を \(\bar{A}\) とし，定常解を \(z(t)=\bar{A}e^{i\omega t}\) とおいて運動方程式に代入します。

\[ (-\omega^2 + 2i\beta\omega + \omega_0^2) \bar{A} e^{i\omega t} = f_0 e^{i\omega t} \]

これより，複素振幅 \(\bar{A}\) は次のようになります。

\[ \bar{A} = \frac{f_0}{(\omega_0^2 - \omega^2) + 2i\beta\omega} \]

複素振幅を極形式 \(\bar{A}=Ae^{-i\phi}\)，\(A>0\) で表すと，定常解は \(z(t)=Ae^{i(\omega t-\phi)}\) となります。その実部 \(x(t)=A\cos(\omega t-\phi)\) は，問題文でおいた式と一致します。

\(\bar{A} = A e^{-i\phi}\) の絶対値をとることで，振幅 \(A\) が得られます。

\[ \finalanswer{A = |\bar{A}| = \frac{f_0}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}}} \]

次に，\(\bar{A}\) の偏角を求めます。

\[ \begin{aligned} e^{-i\phi} &= \cos\phi - i\sin\phi \\ &= \frac{f_0 ( (\omega_0^2 - \omega^2) - 2i\beta\omega )}{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2} \cdot \frac{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}}{f_0} \end{aligned} \]

これより，\(\cos\phi\) と \(\sin\phi\) はそれぞれ次のようになります。

\[ \begin{aligned} \cos\phi &= \frac{\omega_0^2 - \omega^2}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}} \\ \sin\phi &= \frac{2\beta\omega}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}} \end{aligned} \]

\(\beta > 0\) かつ \(\omega > 0\) なので，\(\sin\phi > 0\) です。よって，位相の遅れ \(\phi\) は \(0 < \phi < \pi\) の範囲にあります。\(\omega=\omega_0\) では \(\phi=\dfrac{\pi}{2}\) となり，\(\tan\phi\) は定義されません。それ以外では，\(\tan\phi = \dfrac{\sin\phi}{\cos\phi}\) より次の式が得られます。

\[ \finalanswer{\tan\phi = \frac{2\beta\omega}{\omega_0^2 - \omega^2}\quad(\omega\neq\omega_0)} \]

(3)

(2) で求めた \(A\) の式の分母が最小のとき，振幅 \(A(\omega)\) は最大になります。分母の根号の中を \(g(\omega)\) とおきます。

\[ g(\omega) = (\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2 \]

ここで \(u=\omega^2>0\) とおくと，\(g\) は \(u\) の2次関数として表されます。

\[ \begin{aligned} g(u) &= (\omega_0^2 - u)^2 + 4\beta^2 u \\ &= u^2 - 2(\omega_0^2 - 2\beta^2)u + \omega_0^4 \\ &= \{ u - (\omega_0^2 - 2\beta^2) \}^2 + 4\beta^2(\omega_0^2 - \beta^2) \end{aligned} \]

この2次関数が \(u > 0\) の領域で極小値をとるための条件は，頂点の \(u\) 座標が正であることです。

\[ \omega_0^2 - 2\beta^2 > 0 \]

よって，減衰係数 \(\beta\) が満たすべき条件は次のようになります。

\[ \finalanswer{\beta < \frac{\omega_0}{\sqrt{2}}} \]

この条件が満たされるとき，\(g(u)\) は \(u=\omega_0^2-2\beta^2\) で最小となります。このとき \(A(\omega)\) は最大です。したがって，共鳴角振動数 \(\omega_r=\sqrt{u}\) は次のようになります。

\[ \finalanswer{\omega_r = \sqrt{\omega_0^2 - 2\beta^2}} \]

減衰が小さい極限 \(\beta\to0\) では，\(\omega_r\to\omega_0\) となります。

(4)

(2) で得られた \(\cos\phi\) と \(\sin\phi\) の式から，それぞれの場合の \(\phi\) の値を求めます。

(i) \(\omega \to 0\) のとき

\[ \cos\phi \to 1，\quad \sin\phi \to 0 \quad \implies \quad \finalanswer{\phi \to 0} \]

外力の変化が十分に遅い場合，質点は外力と同じ位相で運動します。この極限では慣性項と抵抗項を無視することができます。そのため，\(kx\approx F_0\cos\omega t\) となります。

(ii) \(\omega = \omega_0\) のとき

\[ \cos\phi = 0，\quad \sin\phi = 1 \quad \implies \quad \finalanswer{\phi = \frac{\pi}{2}} \]

外力の角振動数が固有角振動数と一致すると，変位の位相は \(\dfrac{\pi}{2}\) だけ遅れます。このとき速度は次のようになります。

\[ v(t) = -A\omega_0 \sin(\omega_0 t - \frac{\pi}{2}) = A\omega_0 \cos\omega_0 t \]

速度は外力と同位相になります。そのため，外力は系にエネルギーを与え続けます。

(iii) \(\omega \to \infty\) のとき

\[ \cos\phi \to -1，\quad \sin\phi \to 0 \quad \implies \quad \finalanswer{\phi \to \pi} \]

外力の振動が十分に速い場合，変位は外力と逆位相になります。\(\omega\) が大きい極限では，慣性項がほかの項より大きくなります。そのため，\(-m\omega^2x\approx F_0\cos\omega t\) が成り立ちます。

減衰が十分に小さい場合，振幅は \(\omega_0\) の付近に共鳴ピークをもちます。\(\beta\geq\dfrac{\omega_0}{\sqrt{2}}\) では，振幅は \(\omega>0\) で単調に減少します。

位相の遅れ \(\phi\) は，下図のようにどの場合も角振動数が増えるにつれて \(0\) から \(\pi\) へと変化します。
