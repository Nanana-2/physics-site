コリオリ力の影響

  1. ホーム
  2. 力学
  3. 8. 並進加速系と回転座標系

問題★★☆

鉛直上向きを \(z\) 軸とし，水平面内で反時計回りに一定の角速度 \(\omega\) で回転している無限に広い円盤を考える。この円盤の中心を原点 \(O\) とし，円盤とともに回転する座標系を \(O-xy\) と定める。ここで，\(z\) 軸は回転の軸と一致しており，右手系の直交座標系を構成している。

時刻 \(t=0\) に原点 \(O\) から，質量 \(m\) の小球を回転座標系の \(x\) 軸の正方向へ，円盤に対する速度 \(v_0\) で打ち出す。摩擦と空気抵抗は無視し，鉛直方向では重力と垂直抗力がつりあっているものとする。以下の問いに答えよ。

(1)回転座標系において，角速度ベクトルを \(\boldsymbol{\omega}\)，小球の位置ベクトルを \(\boldsymbol{r} = (x, y, 0)\)，相対速度ベクトルを \(\boldsymbol{v} = (\dot{x}, \dot{y}, 0)\) とする。小球に働く遠心力とコリオリ力の成分をそれぞれ求め，小球の運動方程式の \(x\) 成分および \(y\) 成分を導出せよ。ここで，文字の上の点は時間微分を表す。

(2)複素数 \(z = x + iy\) を導入することにより，(1) で得られた二つの運動方程式を，複素数 \(z\) とその時間微分に関する一本の二階微分方程式に統合せよ。ここで \(i\) は虚数単位を表す。

(3)初期条件として，時刻 \(t = 0\) において \(z = 0\) かつ \(\dot{z} = v_0\) であることを用いて，(2) の微分方程式を解き，小球の座標 \(x\) および \(y\) を時間の関数として求めよ。

(4)慣性座標系 \(O-XY\) を考え，\(t=0\) で回転座標系 \(O-xy\) と一致しているものとする。慣性座標系における小球の軌道を求め，回転座標系へ変換した結果が (3) と一致することを示せ。

解答・解説

回転座標系の運動方程式には，遠心力とコリオリ力が加わります。\(x\) 方向と \(y\) 方向の式には，互いに相手の速度が入っています。複素数 \(z=x+iy\) を使うと，2つの式は1本の式にまとまります。

(1)

回転座標系における質量 \(m\) の粒子の運動方程式は，外力を \(\boldsymbol{F}\) とすると，次のようになります。

\[ m \frac{d^2 \boldsymbol{r}}{dt^2} = \boldsymbol{F} - 2m (\boldsymbol{\omega} \times \boldsymbol{v}) - m \boldsymbol{\omega} \times (\boldsymbol{\omega} \times \boldsymbol{r}) \]

摩擦を無視しているので，水平方向の実在の力は \(\boldsymbol{F}=\boldsymbol{0}\) です。角速度ベクトルは \(\boldsymbol{\omega} = (0, 0, \omega)\) です。位置ベクトルは \(\boldsymbol{r} = (x, y, 0)\)，相対速度ベクトルは \(\boldsymbol{v} = (\dot{x}, \dot{y}, 0)\) です。

まず，コリオリ力 \(\boldsymbol{F}_{\text{cor}} = -2m (\boldsymbol{\omega} \times \boldsymbol{v})\) を計算します。外積の部分は次のようになります。

\[ \boldsymbol{\omega} \times \boldsymbol{v} = (-\omega \dot{y}, \omega \dot{x}, 0) \]

これより，コリオリ力の各成分は次のようになります。

\[ \finalanswer{\boldsymbol{F}_{\text{cor}} = (2m\omega \dot{y}, -2m\omega \dot{x}, 0)} \]

次に，遠心力 \(\boldsymbol{F}_{\text{cf}} = -m \boldsymbol{\omega} \times (\boldsymbol{\omega} \times \boldsymbol{r})\) を計算します。

\[ \begin{aligned} \boldsymbol{\omega} \times \boldsymbol{r} &= (-\omega y, \omega x, 0) \\ \boldsymbol{\omega} \times (\boldsymbol{\omega} \times \boldsymbol{r}) &= (-\omega^2 x, -\omega^2 y, 0) \end{aligned} \]

これより，遠心力の各成分は次のようになります。

\[ \finalanswer{\boldsymbol{F}_{\text{cf}} = (m\omega^2 x, m\omega^2 y, 0)} \]

以上を運動方程式に代入し，両辺を \(m\) で割ります。運動方程式の \(x\) 成分と \(y\) 成分は次のようになります。

\[ \begin{aligned} &\finalanswer{\ddot x=\omega^2x+2\omega\dot y} \\ &\finalanswer{\ddot y=\omega^2y-2\omega\dot x} \end{aligned} \]

(2)

複素数 \(z = x + iy\) を時間で微分すると，\(\dot{z} = \dot{x} + i\dot{y}\)，\(\ddot{z} = \ddot{x} + i\ddot{y}\) となります。(1) で求めた運動方程式の \(y\) 成分の式に \(i\) を掛け，\(x\) 成分の式と足します。

\[ \ddot{x} + i\ddot{y} = \omega^2 (x + iy) + 2\omega (\dot{y} - i\dot{x}) \]

右辺の第2項を，虚数単位 \(i\) を用いて次のように変形します。

\[ \dot{y} - i\dot{x} = -i (\dot{x} + i\dot{y}) = -i\dot{z} \]

これを代入して整理すると，\(z\) についての1本の微分方程式が得られます。

\[ \ddot{z} = \omega^2 z - 2i\omega \dot{z} \]

すべての項を左辺に移項すると，次のようになります。

\[ \finalanswer{\ddot{z} + 2i\omega \dot{z} - \omega^2 z = 0} \]

(3)

(2) で得られた微分方程式は，係数が定数の2階線形同次微分方程式です。この方程式は，特性方程式を用いて解きます。

\[ \lambda^2 + 2i\omega \lambda - \omega^2 = 0 \]

この方程式は，次のように因数分解することができます。

\[ (\lambda + i\omega)^2 = 0 \]

したがって，重解 \(\lambda = -i\omega\) が得られます。重解をもつ場合，一般解は任意の複素定数 \(C_1\)，\(C_2\) を用いて次のように表されます。

\[ z(t) = (C_1 + C_2 t) e^{-i\omega t} \]

初期条件を用います。\(z(0) = 0\) より，次のようになります。

\[ C_1 = 0 \]

よって，解は \(z(t) = C_2 t e^{-i\omega t}\) となります。これを時間 \(t\) で微分します。

\[ \dot{z}(t) = C_2 e^{-i\omega t} - i\omega C_2 t e^{-i\omega t} \]

\(\dot{z}(0) = v_0\) より，次のようになります。

\[ C_2 = v_0 \]

よって，\(z(t)\) は次のようになります。

\[ z(t) = v_0 t e^{-i\omega t} \]

オイラーの公式 \(e^{-i\omega t} = \cos \omega t - i\sin \omega t\) を用いて，実部と虚部に分けます。

\[ z(t) = v_0 t (\cos \omega t - i\sin \omega t) \]

\(z = x + iy\) なので，実部と虚部を比べると，座標 \(x(t)\) と \(y(t)\) は次のようになります。

\[ \begin{aligned} &\finalanswer{x(t)=v_0t\cos\omega t} \\ &\finalanswer{y(t)=-v_0t\sin\omega t} \end{aligned} \]

回転座標系から見ると，小球の軌道は下図のように原点から遠ざかる渦巻きになります。

(4)

慣性座標系 \(O-XY\) から見ると，小球には水平方向の力がはたらきません。したがって，小球は等速直線運動をします。時刻 \(t = 0\) に，小球は原点にあります。速度は \(X\) 軸の正の向きで，大きさは \(v_0\) です。よって，慣性系での運動は次のようになります。

\[ \begin{aligned} &\finalanswer{X(t)=v_0t} \\ &\finalanswer{Y(t)=0} \end{aligned} \]

時刻 \(t\) において，回転座標系 \(O-xy\) は慣性座標系 \(O-XY\) に対して反時計回りに角度 \(\omega t\) だけ回転しています。慣性系における位置 \((X, Y)\) から回転系における位置 \((x, y)\) への変換は，角度 \(\omega t\) だけ時計回りに回す変換になります。

\[ \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} \cos \omega t & \sin \omega t \\ -\sin \omega t & \cos \omega t \end{pmatrix} \begin{pmatrix} X \\ Y \end{pmatrix} \]

この関係式に \(X = v_0 t\) および \(Y = 0\) を代入します。

\[ \begin{aligned} &\finalanswer{x(t)=v_0t\cos\omega t} \\ &\finalanswer{y(t)=-v_0t\sin\omega t} \end{aligned} \]

これは (3) で得られた結果と一致します。

慣性系では，小球は等速直線運動をします。回転座標系では座標軸が回転するので，小球は曲線を描いて見えます。回転座標系の運動方程式では，この曲がりをコリオリ力と遠心力で表します。
