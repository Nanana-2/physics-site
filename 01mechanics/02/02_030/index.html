標準

速度比例抵抗を受ける落下

  1. ホーム
  2. 力学
  3. 2. 運動方程式と力学の基本

問題★★☆

質量 \(m\) の雨粒を質点とみなし，重力加速度 \(g\) の一様な重力場中を鉛直下向きに落下する運動を考える。空気抵抗の大きさは雨粒の速度に比例し，比例定数を \(k>0\) とする。

鉛直下向きを \(y\) 軸の正の向きにとり，雨粒が落下を開始した時刻を \(t = 0\)，初期位置を \(y(0) = 0\)，初期速度を \(v(0) = 0\) と定義する。ただし，速度は \(v(t) = \dfrac{dy}{dt}\) である。

(1)時刻 \(t\) における雨粒の運動方程式を，速度 \(v(t)\) とその時間微分を用いて表せ。

(2)(1) で得られた運動方程式を変数分離法で解き，速度 \(v(t)\) を \(t, m, g, k\) を用いて表せ。

(3)終端速度 \(v_{\infty} = \displaystyle\lim_{t \to \infty} v(t)\) を求めよ。また，運動方程式で加速度を 0 として得られる速度と一致することを示せ。

(4)初期条件 \(y(0) = 0\) のもとで，雨粒の位置 \(y(t)\) を \(t, m, g, k\) を用いて表せ。

解答・解説

空気抵抗が速度に比例するので，運動方程式は速度についての1階の微分方程式です。変数分離で解くことができます。速度は，重力と抵抗力がつり合う値に少しずつ近づいていきます。

(1)

雨粒には，\(y\) 軸の正の向きに重力 \(mg\)，負の向きに大きさ \(kv\) の空気抵抗が作用します。したがって，雨粒の運動方程式は次のようになります。

\[ \finalanswer{m \dfrac{dv}{dt} = mg - kv} \]

(2)

(1) で得られた運動方程式は，速度 \(v\) に関する1階の常微分方程式です。以下のように変数分離します。

\[ \dfrac{dv}{dt} = -\dfrac{k}{m} \left( v - \dfrac{mg}{k} \right) \]

両辺を \(v - \dfrac{mg}{k}\) で割り，両辺を \(t\) で積分します。

\[ \int \dfrac{dv}{v - \dfrac{mg}{k}} = -\int \dfrac{k}{m} dt \]

この積分を計算すると，積分定数を \(C_1\) として次のようになります。

\[ \ln \left| v - \dfrac{mg}{k} \right| = -\dfrac{k}{m} t + C_1 \]

対数の定義から，次のように変形できます。

\[ v - \dfrac{mg}{k} = \pm e^{C_1} e^{-\frac{k}{m} t} \]

ここで \(\pm e^{C_1}\) を新たな定数 \(C\) と置くと，次のように表せます。

\[ v(t) = \dfrac{mg}{k} + C e^{-\frac{k}{m} t} \]

初期条件である \(t = 0\) のとき \(v(0) = 0\) を上式に代入して，定数 \(C\) を求めます。

\[ 0 = \dfrac{mg}{k} + C \implies C = -\dfrac{mg}{k} \]

これをもとの式に代入することで，求める速度 \(v(t)\) が以下のように得られます。

\[ \finalanswer{v(t) = \dfrac{mg}{k} \left( 1 - e^{-\frac{k}{m} t} \right)} \]

(3)

\(t \to \infty\) では \(e^{-\frac{k}{m} t}\) が 0 に収束するため，終端速度は次のようになります。

\[ v_{\infty} = \displaystyle\lim_{t \to \infty} v(t) = \finalanswer{\dfrac{mg}{k}} \]

次に，運動方程式から直接終端速度を導きます。

終端速度では加速度が 0 になります。すなわち，運動方程式において \(\dfrac{dv}{dt} = 0\) とおくと，以下の関係式が得られます。

\[ 0 = mg - kv \]

これを \(v\) について解くと，以下のようになります。

\[ v = \dfrac{mg}{k} \]

これは極限から求めた \(v_{\infty}\) と一致します。このとき，重力と空気抵抗がつり合っています。

速度は時間とともに増加し，終端速度 \(mg/k\) に近づいていきます（下図）。

(4)

速度 \(v(t)\) は位置 \(y(t)\) の時間微分 \(v(t) = \dfrac{dy}{dt}\) であるため，位置 \(y(t)\) は \(v(t)\) を時間で積分することで求められます。

初期条件 \(y(0) = 0\) を用いると，時刻 \(t\) における位置 \(y(t)\) は以下の定積分で表されます。

\[ \begin{aligned} y(t) &= \int_0^t v(\tau) d\tau \\ &= \int_0^t \dfrac{mg}{k} \left( 1 - e^{-\frac{k}{m} \tau} \right) d\tau \end{aligned} \]

この積分を計算します。

\[ \begin{aligned} y(t) &= \dfrac{mg}{k} \left( t + \dfrac{m}{k} e^{-\frac{k}{m} t} - \dfrac{m}{k} \right) \\ &= \dfrac{mg}{k} t - \dfrac{m^2 g}{k^2} \left( 1 - e^{-\frac{k}{m} t} \right) \end{aligned} \]

したがって，求める雨粒の位置 \(y(t)\) は以下のようになります。

\[ \finalanswer{y(t) = \dfrac{mg}{k} t - \dfrac{m^2 g}{k^2} \left( 1 - e^{-\frac{k}{m} t} \right)} \]
