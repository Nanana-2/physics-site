# 摂動法による弱非線形振動

## 問題
三次非線形性をもつダフィング方程式

$$
\frac{\mathrm{d}^2x}{\mathrm{d}t^2} + x + \epsilon x^3 = 0, \quad x(0) = A, \quad \frac{\mathrm{d}x}{\mathrm{d}t}(0) = 0
$$

を考える。ここで $A\ne0$，$0<\epsilon\ll1$ とし，振幅の大きさについても $\epsilon A^2\ll1$ を仮定する。ポアンカレ・リンドステット法に従い，無次元時間 $\tau = \omega t$ を導入し，

$$
\omega = 1 + \epsilon \omega_1 + \dots, \quad x(\tau) = x_0(\tau) + \epsilon x_1(\tau) + \dots
$$

と展開する。以下の問いに答えよ。

(1) 時間変数を $\tau$ に変換し，方程式を展開して $\epsilon^0$ 次および $\epsilon^1$ 次の方程式を導け。

(2) $\epsilon^0$ 次の解 $x_0(\tau) = A \cos\tau$ を $\epsilon^1$ 次の方程式に代入し，$\cos\tau$ に比例する永年項を消去する条件から振動数補正 $\omega_1$ を求めよ。必要であれば三倍角の公式 $\cos^3\tau = \frac{3}{4}\cos\tau + \frac{1}{4}\cos(3\tau)$ を用いよ。

(3) 摂動の1次まで含めた角振動数 $\omega$ を $\epsilon$ と $A$ を用いて表せ。

---

## 解答・解説

<div class="approach" markdown>
非線形の項があると，振動の角振動数が振幅によって変わります。そこで時間を $\tau=\omega t$ と書きかえ，$x$ と $\omega$ を $\epsilon$ で展開します。$\omega$ は，1次の方程式で共振する $\cos\tau$ の項が0になるように求めます。
</div>

### (1)
連鎖律から，$\dfrac{\mathrm{d}}{\mathrm{d}t} = \omega \dfrac{\mathrm{d}}{\mathrm{d}\tau}$ です。そのため，$\dfrac{\mathrm{d}^2x}{\mathrm{d}t^2} = \omega^2 \dfrac{\mathrm{d}^2 x}{\mathrm{d}\tau^2}$ となり，方程式は次のようになります。

$$
\begin{aligned}
\omega^2 \frac{\mathrm{d}^2 x}{\mathrm{d}\tau^2} + x + \epsilon x^3 &= 0
\end{aligned}
$$

展開式を代入すると，

$$
\begin{aligned}
(1 + 2\epsilon \omega_1 + \dots) \frac{\mathrm{d}^2}{\mathrm{d}\tau^2}(x_0 + \epsilon x_1 + \dots) + (x_0 + \epsilon x_1 + \dots) + \epsilon (x_0 + \dots)^3 &= 0
\end{aligned}
$$

となります。したがって，$\epsilon^0$ 次の項を集めると，

$$
\finalanswer{\frac{\mathrm{d}^2 x_0}{\mathrm{d}\tau^2} + x_0 = 0}
$$

が得られます。$\epsilon^1$ 次の項を集めると，

$$
\begin{aligned}
\frac{\mathrm{d}^2 x_1}{\mathrm{d}\tau^2} + 2\omega_1 \frac{\mathrm{d}^2 x_0}{\mathrm{d}\tau^2} + x_1 + x_0^3 &= 0
\end{aligned}
$$

となります。したがって，$\mathrm{d}^2 x_0/\mathrm{d}\tau^2 = -x_0$ を使うと，

$$
\finalanswer{\frac{\mathrm{d}^2 x_1}{\mathrm{d}\tau^2} + x_1 = 2\omega_1 x_0 - x_0^3}
$$

が得られます。

### (2)
$x_0(\tau) = A \cos\tau$ を右辺に代入し，3倍角の公式を使うと，

$$
\begin{aligned}
2\omega_1 (A\cos\tau) - A^3 \cos^3\tau &= 2\omega_1 A \cos\tau - A^3 \left( \frac{3}{4}\cos\tau + \frac{1}{4}\cos(3\tau) \right) \\
&= \left( 2\omega_1 A - \frac{3}{4} A^3 \right) \cos\tau - \frac{1}{4} A^3 \cos(3\tau)
\end{aligned}
$$

となります。$\cos\tau$ の項が残ると，固有角振動数1との共振が起こります。すると，$x_1$ に $\tau \sin\tau$ の形の永年項が現れます。この項は時間とともに増えていきます。摂動展開が長い時間にわたって成り立つには，$\cos\tau$ の係数が0でなければなりません。

$$
\begin{aligned}
2\omega_1 A - \frac{3}{4} A^3 &= 0
\end{aligned}
$$

したがって，$A \neq 0$ より，

$$
\finalanswer{\omega_1 = \frac{3}{8} A^2}
$$

となります。

### (3)
$\omega = 1 + \epsilon \omega_1$ に (2) の結果を代入します。したがって，

$$
\finalanswer{\omega=1+\frac{3}{8}\epsilon A^2+O\!\left((\epsilon A^2)^2\right)}
$$

となります。$\epsilon>0$ は，変位が大きいほど復元力が強くなる硬いばねにあたります。このとき，角振動数は振幅の2乗に比例して増えます。
