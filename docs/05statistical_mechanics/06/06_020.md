# 占有数表示

## 問題
互いに相互作用しない $N$ 個のボース粒子またはフェルミ粒子からなる系を考える。1粒子状態をエネルギーの低い順に $k = 1, 2, 3, \dots$ とし，各準位のエネルギーを $\epsilon_k$ とする。

同種粒子系では，各準位 $k$ にある粒子数 $n_k$ の組 $(n_1,n_2,n_3,\dots)$ を用いて微視的状態を表す。これを占有数表示と呼ぶ。以下の問いに答えよ。

(1) ボース粒子について，準位 $k$ の占有数 $n_k$ がとり得る値を示せ。また，全粒子数が $N$ で固定されているとき，占有数が満たす拘束条件を式で表せ。

(2) フェルミ粒子について，パウリの排他原理を考慮し，準位 $k$ の占有数 $n_k$ がとり得る値を示せ。

(3) 3つの1粒子準位 $k=1,2,3$ に2粒子を配置する。

* 粒子がボース粒子である場合
* 粒子がフェルミ粒子である場合

それぞれについて，占有数の組 $(n_1,n_2,n_3)$ をすべて列挙し，状態数を求めよ。

---

## 解答・解説

<div class="approach" markdown>
占有数表示では，各準位に何個の粒子があるかで状態を表します。ボース粒子は1つの準位に何個でも入ることができ，フェルミ粒子は0個か1個です。粒子は区別できないので，占有数の組1つが1つの状態です。
</div>

### (1)

ボース粒子の波動関数は，座標の入れ替えに対して対称です。複数の粒子が同じ量子状態に入ることに制限はありません。

したがって1つの準位 $k$ の粒子数 $n_k$ は，0以上の任意の整数をとることができます。

$$
\finalanswer{n_k = 0, 1, 2, 3, \dots}
$$

また，カノニカル集団では全粒子数が $N$ に固定されています。そのため，すべての準位の占有数の和は $N$ に等しくなります。

$$
\finalanswer{\sum_{k} n_k = N}
$$

### (2)

フェルミ粒子の波動関数は，座標の入れ替えに対して反対称です。パウリの排他原理により，同じ1粒子状態に2つ以上の粒子が入ることはできません。

したがって，各準位 $k$ の占有数 $n_k$ は0か1のどちらかです。

$$
\finalanswer{n_k = 0, 1}
$$

### (3)

3つの準位に2個の粒子を配置し，$n_1+n_2+n_3=2$ を満たす組を列挙します。

**ボース粒子のケース**
ボース粒子では，同一の準位に2個の粒子が入る $n_k=2$ も許されます。条件を満たす占有数の組は次の6通りです。

$$
\finalanswer{\begin{gathered}(2,0,0),(0,2,0),(0,0,2),\\(1,1,0),(1,0,1),(0,1,1)\end{gathered}}
$$

* 1つの準位に2粒子が固まって入る状態：
  $(2, 0, 0), \ (0, 2, 0), \ (0, 0, 2)$
* 異なる2つの準位に1粒子ずつ分散して入る状態：
  $(1, 1, 0), \ (1, 0, 1), \ (0, 1, 1)$

**フェルミ粒子のケース**

フェルミ粒子では $n_k$ は $0$ または $1$ なので，2個の粒子は異なる準位に1個ずつ入ります。とり得る占有数の組は $\finalanswer{(1,1,0),\ (1,0,1),\ (0,1,1)}$ の3通りです。

* $(1, 1, 0), \ (1, 0, 1), \ (0, 1, 1)$

**全状態数の比較**

したがって，$\finalanswer{W_{\mathrm B}=6,\quad W_{\mathrm F}=3}$ です。
