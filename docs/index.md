## 何のサイト？

本サイトは大学の定期試験から大学院入試までの物理の問題と解説をまとめた問題集サイトです。式が長いので，パソコンで見ることを推奨します。

## AIの利用について

今日，物理の問題の解説はAIに聞けばいくらでも出てきます。作問もAIに作らせることができます。

一方でAIは物事を体系的に知ることに関してはまだ課題があると思っています。これはプロンプトを入力する側が体系的な知識を持っていないことに依るものです。

そこで本サイトでは作成者の学部時代の勉強の経験をAI（Claude Opus 5.5・GPT sol 6.1）に学習させることで，学部4年の夏（院試）までに知っていた話題を問題という形で提供します。

院試を控えている方にとっての対策の目安に，現在進行形で大学物理を学んでいる方には「この分野にはどんな話題があるのか」を体系的に知る一つのきっかけになれば嬉しいです。

## 推奨される使い方

このサイトの問題・解説の殆どはAIが作ったもので，それを見て確かめているのはただの院生です。誤りが残っているかもしれないので，教科書と照らし合わせながら使っていただくことを推奨します。

間違いや気になる点があれば，XのDMで教えていただけると助かります。

## 収録問題・分野 { #fields }

主に大学物理の中でも**物性物理を学ぶ上で基礎となる分野**（力学・電磁気学・熱力学・量子力学・統計力学・物性物理）について，**三段階の難易度のタグ付け**（基本・標準・発展）がされています。目安としては

* **基本**…定期試験に出てくる程度
* **標準**…院試におけるベーシックな問題程度
* **発展**…やや発展的トピック。過去問ではたまに見かけたから知っておいて損はない程度のものから試験ではまずでないトピックまで

です。左側のサイドメニュー，または以下のリンクから各分野の問題へアクセスできます。
