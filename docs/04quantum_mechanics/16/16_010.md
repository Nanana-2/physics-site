# フォック空間と粒子数表示

## 問題
一粒子状態の正規直交完全系を $| 1 \rangle, | 2 \rangle, \dots, | k \rangle, \dots$ とする。各状態に入っている粒子数を $n_1, n_2, \dots, n_k, \dots$ と表すとき，フォック空間の状態ベクトルは粒子数状態 $| n_1, n_2, \dots, n_k, \dots \rangle$ を基底として展開される。以下の問いに答えよ。

(1) 粒子が全く存在しない状態である真空状態を $| 0 \rangle$ とする。真空状態におけるすべての状態の粒子数 $n_k$ を答えよ。また，全粒子数演算子を $\hat{N}$ とするとき，真空状態に対する固有値方程式 $\hat{N} | 0 \rangle = N_0 | 0 \rangle$ の固有値 $N_0$ の数値を答えよ。

(2) 1つの状態に任意の数の粒子が入りうるボソン系を考える。一粒子状態 $| 1 \rangle$ に 2 個，状態 $| 3 \rangle$ に 1 個の粒子が存在し，他の状態には粒子が存在しない多ボソン状態を粒子数表示の記号で書き表せ。また，この状態に全粒子数演算子 $\hat{N}$ を作用させたときの固有値を求めよ。

(3) パウリの排他原理が成り立つフェルミオン系を考える。ボソン系とは異なり，各状態の粒子数 $n_k$ がとりうる値の範囲に制限が生じる。このとき，各 $n_k$ がとりうるすべての数値を個別に列挙せよ。

---

## 解答・解説

<div class="approach" markdown>
同種粒子からなる多粒子系では，粒子に番号を付けて波動関数を書くと，入れかえに対する対称化や反対称化の計算が煩雑になります。

さらに，粒子の生成や消滅によって粒子数が変わる系では，決まった数の変数をもつ波動関数では状態を表すことができません。

そこで，各一粒子状態にいくつの粒子が入っているかを並べて状態を表します。この表し方を，**粒子数表示**または**占有数表示**といいます。

粒子数の異なる状態をまとめて扱う空間を，**フォック空間**といいます。
</div>

### (1)

真空状態では，どの一粒子状態にも粒子が1個も入っていません。したがって，すべての $k$ について，粒子数は次のようになります。

$$
\finalanswer{n_k = 0}
$$

全粒子数演算子 $\hat{N}$ の固有値は，各状態の粒子数 $n_k$ の和です。真空状態 $| 0 \rangle$ ではすべての $n_k$ が 0 なので，全粒子数も 0 です。

したがって，固有値は次のようになります。

$$
\finalanswer{N_0 = 0}
$$

### (2)

粒子数表示の基底 $| n_1, n_2, n_3, \dots \rangle$ の各位置に，粒子の個数を書きます。状態 1 の位置に 2，状態 3 の位置に 1 を書き，それ以外はすべて 0 とします。状態ベクトルは次のように表されます。

$$
\finalanswer{| 2, 0, 1, 0, 0, \dots \rangle}
$$

全粒子数演算子 $\hat{N}$ をこの状態に作用させると，各一粒子状態の粒子数の和が固有値として得られます。

$$
\hat{N} | 2, 0, 1, 0, 0, \dots \rangle = (2 + 0 + 1 + 0 + 0 + \dots) | 2, 0, 1, 0, 0, \dots \rangle
$$

括弧内の和を計算すると，固有値は次のようになります。

$$
\finalanswer{N = 3}
$$

### (3)

フェルミオンの系では，パウリの排他原理によって，同じ状態に2個以上の粒子が入ることはできません。

1つの状態に入る粒子は，0個か1個です。したがって，どの $k$ についても，粒子数 $n_k$ のとりうる値は次の2つに限られます。

$$
\finalanswer{n_k = 0, 1}
$$
