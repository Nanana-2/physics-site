# 東大理物 平成9年度 一般教育科目 数学 第3問：原始ピタゴラス数の生成公式

## 問題

$$
x^2 + y^2 = z^2 \qquad \text{(1)}
$$

を満たす正の整数 $x, y, z$ の組み合わせをすべて求める方法を考える。ここで $x, y, z$ のどの2つも，たがいに素（最大公約数が $1$）とする。
{: .problem-lead }

(a) $x$ と $y$ は，一方が偶数，もう一方が奇数であることを証明せよ。

(b) 以下では，偶数の方を $x$ とする。残りの $y$ と $z$ の2数から，$A = (z + y)/2$，$B = (z - y)/2$ と定義するとき，$A$ と $B$ は整数であり，かつ，たがいに素であることを証明せよ。

(c) 一般に，たがいに素な正の整数 $A$ と $B$ の積が正の整数 $C$ の2乗，すなわち

$$
A \cdot B = C^2 \qquad \text{(2)}
$$

で表せる場合，$A = \alpha^2$，$B = \beta^2$ となる整数 $\alpha, \beta$ が存在することを証明せよ。

(d) (1) 式を満たす3つの整数 $x, y, z$ を，2つの整数 $\alpha, \beta$（ここで $\alpha > \beta > 0$）から導く式を示せ。

(e) (d) の結果を用いて，$\alpha \le 6$ の範囲で，たがいに素なすべての $x, y, z$ の組み合わせを示せ。

## 解答・解説

<div class="approach" markdown>
平方数の $4$ を法とする余りは $0$ または $1$ のみであることを用いると，$x, y$ の偶奇が異なることが分かります。$x^2 = (z + y)(z - y)$ を $4$ で割った等式 $(x/2)^2 = A B$ に素因数分解の一意性を用いることで，すべての原始ピタゴラス数を2つの整数 $\alpha, \beta$ で完全にパラメータ化できます。
</div>

### (a)

$x$ と $y$ がともに偶数であると仮定すると，$x$ と $y$ は公約数 $2$ をもち，たがいに素であるという仮定に反します。

次に，$x$ と $y$ がともに奇数であると仮定します。このとき整数 $k, l$ を用いて $x = 2k + 1$，$y = 2l + 1$ とおけるため，$x^2 + y^2$ を計算すると次式が得られます。

$$
\begin{aligned}
x^2 + y^2 &= (2k + 1)^2 + (2l + 1)^2 \\
&= 4(k^2 + k + l^2 + l) + 2
\end{aligned}
$$

したがって $z^2 = x^2 + y^2$ は $4$ で割った余りが $2$ となります。しかし，任意の整数 $z$ について，$z = 2m$ ならば $z^2 = 4m^2$ は $4$ で割り切れ，$z = 2m + 1$ ならば $z^2 = 4(m^2 + m) + 1$ は $4$ で割った余りが $1$ となるため，$z^2$ を $4$ で割った余りが $2$ になることはあり得ません。よって $x$ と $y$ がともに奇数であることも矛盾します。

以上より，$x$ と $y$ は一方が偶数，もう一方が奇数であることが証明されました。

### (b)

$x$ が偶数であり，$y$ は (a) より奇数です。このとき $x^2$ は偶数，$y^2$ は奇数なので，$z^2 = x^2 + y^2$ は奇数となり，したがって $z$ も奇数です。

奇数同士の和 $z + y$ および差 $z - y$ はいずれも偶数であるため，

$$
A = \frac{z + y}{2}, \qquad B = \frac{z - y}{2}
$$

はともに整数です。なお $z > y > 0$ より $A > B > 0$ も成り立ちます。

次に $A$ と $B$ がたがいに素であることを示します。$A$ と $B$ の正の公約数を $d$ とおくと，$d$ は $A + B$ と $A - B$ の両方を割り切ります。ここで

$$
A + B = z, \qquad A - B = y
$$

なので，$d$ は $z$ と $y$ の公約数です。仮定より $y$ と $z$ はたがいに素であるため $d = 1$ に限られます。よって $A$ と $B$ の最大公約数は $1$ であり，たがいに素であることが証明されました。

### (c)

$A = 1$ または $B = 1$ のときは，それぞれ $\alpha = 1, \beta = C$ または $\alpha = C, \beta = 1$ とおけば主張が成り立ちます。

$A \ge 2$ かつ $B \ge 2$ の場合を考えます。素因数分解の一意性より，$A, B, C$ は素数の積として一意に表されます。$A \cdot B = C^2$ の右辺 $C^2$ の素因数分解においては，現れるすべての素因数の指数が偶数です。

一方，$A$ と $B$ はたがいに素なので，共通の素因数をもちません。したがって，$A$ を割り切る任意の素数 $p$ に対して，$A$ における $p$ の指数は $A \cdot B = C^2$ における $p$ の指数に一致し，偶数となります。よって $A$ の素因数分解は

$$
A = p_1^{2e_1} p_2^{2e_2} \cdots p_r^{2e_r}
$$

の形をとり，$\alpha = p_1^{e_1} p_2^{e_2} \cdots p_r^{e_r}$ とおけば $A = \alpha^2$ となります。同様に $B$ のすべての素因数の指数も偶数であるため，正の整数 $\beta$ が存在して $B = \beta^2$ となります。

### (d)

式 (1) を変形すると $x^2 = (z + y)(z - y)$ となります。$x$ は偶数なので正の整数 $C = \dfrac{x}{2}$ を定義でき，両辺を $4$ で割ると次式が得られます。

$$
\left(\frac{x}{2}\right)^2 = \frac{z + y}{2} \cdot \frac{z - y}{2}
$$

すなわち $A \cdot B = C^2$ が成り立ちます。(b) より $A, B$ はたがいに素な正の整数なので，(c) の結果から正の整数 $\alpha, \beta$ を用いて

$$
A = \alpha^2, \qquad B = \beta^2
$$

となります。ここで $A > B > 0$ より $\alpha > \beta > 0$ であり，$C = \sqrt{AB}$ より $\dfrac{x}{2} = \alpha\beta$ です。これらを $A = \dfrac{z + y}{2}$ および $B = \dfrac{z - y}{2}$ と合わせて $x, y, z$ について解くと，次式が得られます。

$$
x = 2\alpha\beta, \qquad y = \alpha^2 - \beta^2, \qquad z = \alpha^2 + \beta^2
$$

さらに，$x, y, z$ がどの2つもたがいに素であるための $\alpha, \beta$ の条件を確認します。$A = \alpha^2$ と $B = \beta^2$ がたがいに素であることより $\alpha$ と $\beta$ はたがいに素です。また $y = \alpha^2 - \beta^2$ が奇数であることから，$\alpha$ と $\beta$ は一方が偶数，もう一方が奇数すなわち $\alpha + \beta$ が奇数でなければなりません。逆に $\alpha > \beta > 0$，$\gcd(\alpha, \beta) = 1$ かつ $\alpha + \beta$ が奇数であれば，$y, z$ はともに奇数で，$y, z$ に共通の素因数 $p$ があれば $p$ は奇数であり $z + y = 2\alpha^2$ と $z - y = 2\beta^2$ の両方を割り切るため $\alpha, \beta$ の公約数となって矛盾します。よって $x, y, z$ はどの2つもたがいに素となります。

$$
\finalanswer{x = 2\alpha\beta,\qquad y = \alpha^2 - \beta^2,\qquad z = \alpha^2 + \beta^2}
$$

ただし $\alpha, \beta$ は $\alpha > \beta > 0$ でたがいに素，かつ偶奇が異なる整数です。なお $x$ と $y$ の役割を入れ替えた組 $(y, x, z)$ も式 (1) の解です。

### (e)

(d) で示した条件である $\alpha > \beta > 0$，$\gcd(\alpha, \beta) = 1$，かつ $\alpha$ と $\beta$ の偶奇が異なる組を $\alpha \le 6$ の範囲ですべて列挙し，$(x, y, z) = (2\alpha\beta, \alpha^2 - \beta^2, \alpha^2 + \beta^2)$ を計算します。

- $\alpha = 2$ のとき，条件を満たすのは $\beta = 1$ のみで，$(x, y, z) = (4, 3, 5)$ です。
- $\alpha = 3$ のとき，条件を満たすのは $\beta = 2$ のみで，$(x, y, z) = (12, 5, 13)$ です。
- $\alpha = 4$ のとき，条件を満たすのは $\beta = 1, 3$ であり，それぞれ $(8, 15, 17)$ と $(24, 7, 25)$ です。
- $\alpha = 5$ のとき，条件を満たすのは $\beta = 2, 4$ であり，それぞれ $(20, 21, 29)$ と $(40, 9, 41)$ です。
- $\alpha = 6$ のとき，奇数のうち $6$ とたがいに素なのは $\beta = 1, 5$ のみであり，$\beta = 3$ は $\gcd(6, 3) = 3$ のため除かれます。それぞれ $(12, 35, 37)$ と $(60, 11, 61)$ です。

以上を一覧にまとめます。

| $\alpha$ | $\beta$ | $x = 2\alpha\beta$ | $y = \alpha^2 - \beta^2$ | $z = \alpha^2 + \beta^2$ |
| :---: | :---: | :---: | :---: | :---: |
| $2$ | $1$ | $4$ | $3$ | $5$ |
| $3$ | $2$ | $12$ | $5$ | $13$ |
| $4$ | $1$ | $8$ | $15$ | $17$ |
| $4$ | $3$ | $24$ | $7$ | $25$ |
| $5$ | $2$ | $20$ | $21$ | $29$ |
| $5$ | $4$ | $40$ | $9$ | $41$ |
| $6$ | $1$ | $12$ | $35$ | $37$ |
| $6$ | $5$ | $60$ | $11$ | $61$ |

$$
\finalanswer{(x, y, z) = (4, 3, 5),\ (12, 5, 13),\ (8, 15, 17),\ (24, 7, 25),\ (20, 21, 29),\ (40, 9, 41),\ (12, 35, 37),\ (60, 11, 61)}
$$
