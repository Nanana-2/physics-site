# 熱力学ポテンシャルの自然変数

## 問題
熱力学第一法則の微分形式 $dU = T dS - P dV$ を基本式として，以下の問いに答えよ。

(1) エンタルピー $H = U + PV$ の全微分 $dH$ を計算し， $dS$ と $dP$ を用いた形式で表せ。また，この式からエンタルピーの自然な変数が $S$ と $P$ であることを示せ。

(2) ヘルムホルツ自由エネルギー $F = U - TS$ の全微分 $dF$ を計算し， $dT$ と $dV$ を用いた形式で表せ。また，この式からヘルムホルツ自由エネルギーの自然な変数が $T$ と $V$ であることを示せ。

(3) ギブズ自由エネルギー $G = H - TS$ の全微分 $dG$ を計算し， $dT$ と $dP$ を用いた形式で表せ。また，この式からギブズ自由エネルギーの自然な変数が $T$ と $P$ であることを示せ。

---

## 解答・解説

<div class="approach" markdown>
どのポテンシャルも，$U$ に積 $PV$ や $TS$ を足し引きしたものです。積の微分で出る項が $dU$ の項と打ち消し合い，微分の変数が入れかわります。全微分に残った微小量の変数を，そのポテンシャルの自然な変数といいます。
</div>

### (1)
エンタルピーの定義式の両辺について全微分をとります。積の微分公式を用いると次のようになります。

$$
dH = dU + P dV + V dP
$$

この式に，内部エネルギーの全微分形式 $dU = T dS - P dV$ を代入します。

$$
dH = (T dS - P dV) + P dV + V dP
$$

右辺の $P\,dV$ の項は打ち消し合います。残りを整理すると，次のようになります。

$$
\finalanswer{dH = T dS + V dP}
$$

この式の右辺の微小量は $dS$ と $dP$ です。$S$ と $P$ を独立変数に選ぶと，$dS$ と $dP$ の係数は温度 $T$ と体積 $V$ という状態量だけで表されます。したがって，エンタルピーの自然な変数は $S$ と $P$ です。自然な変数を用いると，$\finalanswer{H=H(S,P)}$ と書くことができます。

### (2)
ヘルムホルツ自由エネルギーの定義式の両辺について全微分をとります。積の微分公式を用いると次のようになります。

$$
dF = dU - T dS - S dT
$$

この式に，基本式である $dU = T dS - P dV$ を代入します。

$$
dF = (T dS - P dV) - T dS - S dT
$$

右辺の $T\,dS$ の項は打ち消し合います。残りを整理すると，次のようになります。

$$
\finalanswer{dF = -P dV - S dT}
$$

この式の右辺の微小量は $dV$ と $dT$ です。$V$ と $T$ を独立変数に選ぶと，$dV$ と $dT$ の係数は圧力 $P$ とエントロピー $S$ だけで表されます。したがって，ヘルムホルツ自由エネルギーの自然な変数は $T$ と $V$ です。自然な変数を用いると，$\finalanswer{F=F(T,V)}$ と書くことができます。

### (3)
ギブズ自由エネルギーの定義式の両辺について全微分をとります。積の微分公式を用いると次のようになります。

$$
dG = dH - T dS - S dT
$$

この式に，(1) で導いたエンタルピーの全微分 $dH = T dS + V dP$ を代入します。

$$
dG = (T dS + V dP) - T dS - S dT
$$

右辺の $T\,dS$ の項は打ち消し合います。残りを整理すると，次のようになります。

$$
\finalanswer{dG = V dP - S dT}
$$

この式の右辺の微小量は $dP$ と $dT$ です。$P$ と $T$ を独立変数に選ぶと，$dP$ と $dT$ の係数は体積 $V$ とエントロピー $S$ だけで表されます。したがって，ギブズ自由エネルギーの自然な変数は $T$ と $P$ です。自然な変数を用いると，$\finalanswer{G=G(T,P)}$ と書くことができます。
